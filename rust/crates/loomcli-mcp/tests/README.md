# Test map

Each row is one file of `typescript/packages/mcp/tests`. A count is the number of Rust test functions that carry the file's cases; an `it.each` or `test.each` table runs as one function over its rows. `tests/common/mod.rs` is the port of the reference's `session.ts` and `fixtures/server.mjs`: the server runs in process over two in-memory pipes, and the fixture reports what a handler saw to a shared log where the reference's writes to stderr. `tests/http_support/` is the port of `http.ts`: `mod.rs` is its fixture server, a listener on 127.0.0.1 on a free port that hands each socket to the transport, and `client.rs` its client, an HTTP/1.1 client over a raw socket that the MCP plugin's HTTP tests include by path, as the reference's plugin tests import `http.ts`.

A test that fakes the reference's timers pauses the runtime's clock with `fake_timers()`. A blocking task in flight keeps the paused clock from advancing on its own while a socket is awaited, and `FakeTimers::advance` releases it for one sleep of the span, so the runtime fires each timer due by then in deadline order, as `vi.advanceTimersByTime` does. A wait for a socket is bounded in real time.
