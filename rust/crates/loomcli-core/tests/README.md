# Reference test map

The TypeScript reference's tests are the behavioral oracle. Each row names one test file under `typescript/packages/core/tests` and its status: ported (with the Rust test file), partly ported (with what remains and the stage it belongs to), a later stage, or not applicable (with the reason). The cases stages 2.5 and 2.6 closed without porting (the former unported backlog) are ported now, beside the files the rows name, or each row says why they do not apply. Two rows, `content.test.ts` and `interaction.test.ts`, keep help cases that wait on the help plugin's tests in `loomcli-plugins`. Stage numbers name the stages core was built in: 2.1 host and failures, 2.2 declarations and graph, 2.3 parser, 2.4 inputs, 2.5 output and the failure path, 2.6 plugins and the run, and 2.7 derive and testing. A path with no crate named is under `crates/loomcli-core`.
