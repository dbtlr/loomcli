# Test map: the skills plugin

Reference tests live in `typescript/packages/plugins/tests`. The Rust tests drive the plugin through its public surface (`skills()`, `Skill`, `SkillFile`, `refresh_skills`) on the mock process, in a temporary sandbox of a home, a state directory, and a repository under the system's temporary folder, and assert exact stderr lines, files, modes, record bytes, and exit codes. `tests/skills_support/mod.rs` is the port of `fixtures/skills-run-app.ts`; `tests/skills_data/` holds the files the module rustdoc's example embeds with `include_bytes!`.

| Reference file | Status | Notes |
| --- | --- | --- |
| `skills.test.ts` | ported, 70 of 70 | `skills_global.rs` (installing 15, refusing 11, forcing 5, updating 6, uninstalling 6, one folder for both targets 3), `skills_project.rs` (14), `skills_umask.rs` (the two umask rows of the first install case and the project install's modes under umask 077, in one test because the umask is process-wide: 3 rows), `skills_loading.rs` (loading: no loader outside `skills`, each loader once in order, the three pinned file faults for `install`, `update`, and `install --project`, a loader that fails). `it.each` rows count one each, and several run as one test over their rows. The `the Commands` case asserts the descriptions, the `--agent` set, the `-C`/`--directory` spelling, and the exit 2 of `update --agent` from the declared graph (`inspect()`) and a run, because the `--help` text belongs to the help plugin.
