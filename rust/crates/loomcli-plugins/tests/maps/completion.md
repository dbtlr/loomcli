# Test map: the completion plugin

Reference tests live in `typescript/packages/plugins/tests`. The plugin's tests drive it through its public surface on the mock process (`Application::run` with `mock_process`) and assert exact stdout, stderr, and exit codes. File-system cases run in a temporary folder under the system's temporary folder, never the real home, and run as the current user (the fixture host reports that user's ID, as the reference's fixture reports `process.getuid()`). The helpers a case shares are in `tests/completion_support/` (the `kit` application of `fixtures/completion-app.ts`, in `mod.rs`; the `jsonkit` application, the sandbox, the scenario, and the fixture `pwsh` of `fixtures/completion-install-app.ts`, in `install.rs`).

| `completion-shells.test.ts` | partly ported, 15 cases | The suite types each line into a real Bash, Zsh, Fish, and PowerShell through a pseudo-terminal and reads back what Tab leaves. `completion_bash_driver.rs` runs the printed Bash script in a real Bash without a terminal: it sets the variables Bash sets for a completion function, calls `__start_kit`, and reads `COMPREPLY`, with a stub program that prints the answer this plugin's `__complete` wrote for the same words and logs the words it received.
