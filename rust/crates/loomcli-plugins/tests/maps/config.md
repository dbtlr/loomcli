# Test map: the configuration plugin

The plugin is `config` and its declarations module is `config-extension`. Reference tests live in `typescript/packages/plugins/tests`. The Rust tests are `tests/config_*.rs` with the fixture in `tests/config_support/mod.rs`, and unit tests beside each parser and rule in `src/config`, run with `cargo test -p loomcli-plugins --no-default-features --features config`. The reference's fixture installs `help()` beside the plugin; help is another package, so the Rust fixture installs a stand-in that declares the same `--help` control option, takes the run over, and adds help's `Run "app --help" to see the usage.` hint under a usage failure. The reference's schemas are zod schemas; the Rust fixture's are serde types of the same shape (`Loose`, `Refined`, `TopRefined`, `Typed`) with a hand-written JSON Schema each, and the drop messages are this port's serde wording (see the Configuration plugin rows of `docs/deviations.md`).
