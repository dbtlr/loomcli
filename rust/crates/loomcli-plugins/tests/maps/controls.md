# Test map: the control and look plugins

The plugins are `version`, `color`, `verbose`, `background`, `theme` (the Loom theme and the bare theme), `interaction`, and `suggestions`. Reference tests live in `typescript/packages/plugins/tests`. The Rust tests are `tests/controls_*.rs`, run with `cargo test -p loomcli-plugins --no-default-features --features "version format color verbose background theme interaction suggestions"`. A fixture that the reference runs through `help()` or `manifest()` prints a themed token or reads the graph instead, because those plugins belong to other packages.
