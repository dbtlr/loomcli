# Test map: the self-update plugin

Reference tests live in `typescript/packages/plugins/tests` and `typescript/packages/loom/tests`. The Rust tests drive the plugin through its public surface (`self_update()`, `SelfUpdate`, `AfterReplaceContext`, `Transport`, `TransportResponse`) on the mock process, in a temporary sandbox of a home, a state directory, a cache directory, and an install directory under the system's temporary folder, and assert exact stderr lines, the binary's, record's, and cache's bytes, modes, staging files, the URLs the fake GitHub answered, the hook's calls, and exit codes. `tests/self_update_support/mod.rs` is the port of `fixtures/self-update-app.ts` and `fixtures/self-update-mock.ts`: the fake GitHub is a `Transport` with the reference's rules (a status, hops, `insecure`, `loop`, `no-response`, `lock`, `cut`, `late-abort`, `offsite`, `abort`), and the `notes` application with its `add`, `fail`, `cancel`, and `interrupt` Commands. Unit tests in `src/self_update/` cover the version, `SHA256SUMS`, feed, cache, and path helpers the reference tests import from its source.
