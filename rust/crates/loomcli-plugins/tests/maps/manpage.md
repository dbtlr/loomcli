# Test map: the man page plugin

Reference tests live in `typescript/packages/plugins/tests`. The Rust tests drive the plugin through its public surface (`manpage()`, `refresh_manpages`, and the `#[doc(hidden)]` `manpage::test_support` and `manpage::roff` exports for the page renderer and the roff writer) on the mock process, in a temporary sandbox of two homes, a state directory, and a working directory under the system's temporary folder, and assert exact stdout, stderr, files, modes, record bytes, and exit codes. `tests/manpage_support/mod.rs` is the port of `fixtures/manpage-app.ts` and the sandbox helpers of `manpage.test.ts`.

Added beyond the reference: `manpage_conformance.rs` compares the pages of a reduced jsonkit (`get`, with details, argument, content option, and examples, and the manpage plugin's four children and group) against the shared files of `jsonkit-manpage-generate`. The reduced `get` Command declares only the file option, so the test compares its introduction and examples byte for byte and checks the file option. Also `--out` resolved with dot parts and a trailing slash, and a recorded set of one page reading `1 man page`.
