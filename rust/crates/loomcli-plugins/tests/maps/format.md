# Test map: the formatter plugin

The plugin is `format` and its machine views are `format-views`. Reference tests live in `typescript/packages/plugins/tests`. The Rust tests are `tests/format_*.rs`, run with `cargo test -p loomcli-plugins --features format,help,completion,manifest`. The field and group suites use the real help plugin. The older plugin cases use the graph for the help-row checks. The failure cases use a fixture hook for the usage hint, with the same bytes as the reference.
