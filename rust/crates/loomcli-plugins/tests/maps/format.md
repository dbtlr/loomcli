# Test map: the formatter plugin

The plugin is `format` and its machine views are `format-views`. Reference tests live in `typescript/packages/plugins/tests`. The Rust tests are `tests/format_*.rs`, run with `cargo test -p loomcli-plugins --no-default-features --features format`. The reference installs `help()` and `version()` ahead of the formatter in its fixtures; those plugins belong to other packages, so a Rust fixture installs the formatter alone and a case that read help's page or hint reads the graph or the bare diagnostic instead. The failure tests install a fixture plugin after the formatter whose `on_failure` writes help's usage hint for a usage error from argv, so the lines carry `"hints":["Run \"app count --help\" to see the usage."]` as the reference's do; an action failure carries `"hints":[]`
