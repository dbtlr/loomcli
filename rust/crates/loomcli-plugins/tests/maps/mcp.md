# Test map: the MCP plugin

Reference tests live in `typescript/packages/plugins/tests`. The Rust tests drive the plugin through its public surface (`mcp()`, `MCP_COMMAND`, `MCP_INPUT`, `MCP_ARGUMENT`) and assert exact protocol lines, stdout, stderr, record JSON, and exit codes. `tests/mcp_support/mod.rs` is the port of the reference's session helper (`packages/mcp/tests/session.ts`) and the serving half of `fixtures/mcp.mjs`: it runs an application's `mcp` Command in process on the mock process with a stdin the test writes one line at a time and a stdout it reads one message at a time, so the reference's child-process sessions become in-process sessions with the same requests and answers. The fixture applications of `fixtures/mcp-app.ts` and `fixtures/invalid-mcp-input.mjs` are rebuilt in each test file. Where a reference fixture writes `started <label>` and `aborted <label>` to the process's own stderr, the Rust fixture reports them to a shared log the test reads, and the test asserts that stderr stays empty.
