# Test map: the dotenv and logging plugins

Reference tests live in `typescript/packages/plugins/tests`. The Rust tests are `tests/dotenv_plugin.rs`, `tests/logging_records.rs`, `tests/logging_rotation.rs`, `tests/logging_failures.rs`, `tests/logging_controls.rs`, `tests/logging_extension.rs`, and `tests/logging_otel.rs` (with the fixture in `tests/logging_support/`), plus the unit tests in `src/logging/file.rs`. Run them with `cargo test -p loomcli-plugins --no-default-features --features "config dotenv logging"`. Every case runs through `Application::run` (or `invoke`) on the mock process with a temporary directory.
