- Add the plain switch, which turns off redrawing in place so a progress line and a streamed message only ever append to the screen, for an operator whose screen reader or terminal copes badly with redrawing and one who keeps a readable record of a run. Core turns it on in every application when `ACCESSIBLE` is set and not empty, and the new plain plugin, `@loomcli/plugins/plain`, gives the operator `--plain` for one run. With it on, a terminal destination does not redraw in place, as under `TERM=dumb`: a progress line prints its start and end lines and nothing between, and a streamed message is written a line at a time. Messages, color, verbosity, and whether a question asks are unchanged, so `-q`, `--no-input`, and `NO_COLOR` each keep their own job. The [output reference](docs/core/output.md#the-plain-switch) states the contract.
- Add the `plain` mark to `@loomcli/core`'s Boolean global options, which an application puts on its own option for another spelling, under the new rule `@loomcli/core/plain-mark`. `OptionNode`'s Boolean variant and the manifest's Boolean option entry gain `plain`.
