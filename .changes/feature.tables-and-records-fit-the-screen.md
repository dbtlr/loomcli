- Fit `@loomcli/plugins/table` to the terminal. When the natural width exceeds `columns`, the widest columns shrink by levelling from the top, down to the widest unit `wrap` keeps whole in each column, and cells and headers wrap inside their columns with every line keeping the column's alignment. Each line ends at its rightmost cell that has text, with no padding or gap after it. A table whose columns cannot fit at those floors prints one `HEADER  value` block per row instead, and an empty sequence prints its header line at the fitted widths. Off a terminal the output is unchanged, a multi-line `format` cell included. See [Table](docs/core.md#table).
- Wrap each value of `@loomcli/plugins/records` at the width left after its key column, with every continuation line indented under the value. Each streamed row reads its own width, and off a terminal the output is unchanged. See [Records](docs/core.md#records).
- Keep each filesystem path and URL in the first-party completion, manpage, skills, service, self-update, and configuration messages whole when a lane wraps, with `nowrap`. The message text is unchanged, so a path that holds spaces copies exactly and pipes the same bytes.
