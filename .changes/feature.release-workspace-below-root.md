- Allow the hidden `loom release plan`, `loom release cut`, `loom release record`, and `loom pr check` to run in a pnpm workspace below the git root. Each command reads the workspace from its working directory, reads `docs/decisions/` at the git root, and gives the same plan, cut, record, and verdict as for a workspace at the root, whatever the repository's `diff.relative` setting. A plan's `libraries[].directory` stays relative to the workspace directory.
- Change the four commands to refuse a directory that holds no `pnpm-workspace.yaml`, such as a package folder, before they read anything, with exit status 1 and `Run <command> from the workspace directory, the one that holds pnpm-workspace.yaml.`, as in `Run pr check from the workspace directory, the one that holds pnpm-workspace.yaml.` `loom release cut` refuses with `--dry-run` too, and its sentence replaces `Run release cut from the repository root.` Before, `loom pr check` and `loom release plan` failed there on what they read instead, such as with git's own text, and `loom release record --plan <path>`, which read no workspace file, ran from a package folder; it refuses there now, as the others do.
- Allow a history in which the workspace moves from the git root to a directory below it. A read of the workspace at an earlier revision, such as the libraries at a pull request's merge base or the version an earlier commit set, finds the workspace where that revision held `pnpm-workspace.yaml`: in the working directory, else at the git root. `loom pr check` judges the pull request that makes the move as any build-affecting pull request, and a pending fragment the move carries unchanged is not one it adds. The first `loom release cut` after the move takes its material-change baseline from the release before it, keeps the landing order of each fragment the move carried, places a fragment that reuses the name of one consumed before the move where it landed, and reports a library whose files the move carried unchanged as unchanged, even when the move edits another library's file.
- Change the failure for a workspace with no publishable library to read `No publishable libraries in packages/*, so run the command in a workspace directory, the one that holds pnpm-workspace.yaml, whose packages/* holds a package that is not private.`, in place of `No publishable libraries in packages/*, so run the command at the root of a repository whose packages/* holds a package that is not private.`
