- Add `--unmanaged` to the `install.sh` that `loom init` manages. It installs a verified side copy of the binary and writes no `install.json`, prints no PATH advice, and runs no post-install command, so running it beside a live install leaves that install's record, and its self-update, as they were. A declared post-install command is printed as skipped, as `--skip-post-install` prints it. Run `loom init` to render the new script; see [the installer script](docs/toolchain/install.md).
