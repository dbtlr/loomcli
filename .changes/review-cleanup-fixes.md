- Fix a streamed message costing each chunk time in the square of a long run of spaces or tabs inside one line, on a terminal and off one: a run of 16,000 spaces took about 0.65 seconds a chunk. The trailing run a streamed message holds back is now found in time linear in its length, and the bytes written are unchanged.
- Fix a streamed `print` on a terminal, under a rendering policy that keeps terminal controls, counting the payload of a DCS, SOS, PM, or APC string as visible text and writing the string's terminator in a separate write. Such a string is now written whole, terminator included, and takes no width.
- Fix the `loom` bin's sentence for a path it is denied creating or removing, which spoke of execute access to each folder above the path: it now says to give write access to the folder that holds it. A create that meets a link to a missing path names the link instead of saying the path does not exist.
- Fix a service install, or another install that writes a unit file or the installation record, failing with "Something went wrong." and no path when a file sits where a folder belongs on the way to that file, or when the folder cannot be written. It now names the path it could not write and says to remove or rename the file, or to make the location writable, then run the command again.
