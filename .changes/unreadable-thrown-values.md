- Fix how a run reports a thrown value whose prototype chain cannot be read. A thrown proxy whose prototype chain never ends no longer hangs a run under Bun; it exits 1, as it does under Node. In a cancelled run, a proxy whose prototype trap throws, or an Error whose `name` getter throws, now reports as a foreign throw: the generic message in a distributed build, and the `@loomcli/core/foreign-throw` Developer Diagnostic in a development build, where it printed `Could not write invocation output.` before. The run keeps its signal's code. A configuration source that throws such a value reports `Plugin "@acme/config" failed in its configuration source: The thrown value has no readable message.`, where the proxy's own error or a stack overflow escaped before. A row view that throws such a value reports a foreign throw with that message, and an `onCommandAttach` hook that throws one reports its `@loomcli/core/broken-attach-hook` fault with it; an option or argument `default` that throws one is an unreadable declaration at its declaring call. See the [core reference](docs/core.md).
- Fix `run()` rejecting when an action catches its row source's failure and rethrows an Error whose `cause` cannot be read. The run now resolves 1 and reports both the rethrown Error and the source's failure.
