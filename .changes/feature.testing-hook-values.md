- Add `environmentContext`, `logEvent`, `logDestination`, and `progressEvent` to `@loomcli/testing`, so a test calls an `onEnvironment` hook, an `onLog` hook, or a progress observer with only the members it checks, as the [testing reference](docs/libs/testing.md#environmentcontext) shows. A log event, a log destination, or a progress event takes a fixed default for each member a test does not state, and an unstated `host` member of the environment hook's context throws a sentence that names it when read. A release that adds a member to `Log`, `LogEvent`, `LogDestination`, `EnvironmentContext`, or `ProgressEvent` no longer breaks such a test.
