- Export the types an author needs to name the input of a `@loomcli/validators`, `@loomcli/prompts`, or `@loomcli/testing` function or the value it returns. `@loomcli/validators` exports each factory's options, `TextOptions`, `IntegerOptions`, `NumberOptions`, `UrlOptions`, `DateTimeOptions`, `DurationOptions`, and `PathOptions` with the `PathAccess` and `PathKind` it takes, and `createValidator`'s `ValidatorDefinition` and `ParseReturn` and `issueCode`'s `IssueCodeConfig`. `@loomcli/prompts` exports `PromptContext`, the context a question takes, so a helper that asks a question can name it. `@loomcli/testing` exports `Write`, the entry a `MockProcess`'s `transcript` holds.
- Mark every export of `@loomcli/validators`, `@loomcli/prompts`, `@loomcli/prompts/views`, `@loomcli/testing`, and `@loomcli/eslint-plugin` with the TSDoc tag `@public`, and mark with `@sealed` every type the library builds and every class an author must not subclass, as the [public exports](docs/core/public-exports.md) page describes. The testing builders' inputs stay unsealed, and the contexts and handles they return are sealed. In `@loomcli/prompts`, the types an author writes stay unsealed: the question settings, `MultiselectSettings` included, the choice types `Choice`, `ChoiceEntry`, `ChoiceObject`, `Separator`, and `ChoiceSource`, and `questionFrame`'s data, `QuestionFrame`, `TypedFrame`, `ListFrame`, `ChoiceRow`, and `SeparatorRow`, which an application may build by hand. `Answer` and `ChoiceAnswer`, the values a question resolves to, are sealed. An editor shows the tags on hover.
