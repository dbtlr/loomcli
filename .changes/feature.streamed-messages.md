- Allow `out.print`, `info`, `success`, `warn`, `error`, `debug`, and `trace` to take an async iterable of text in place of the message, so text such as a model's answer shows as it arrives. A streamed message keeps its method's destination and verbosity, draws through the lane view, takes no view, and once it ends has written what the method writes for the joined text. On a terminal each chunk shows as it arrives above any live region; on a pipe, a file, or a captured run each line is written once it completes. A hidden stream is read to its end, and a stream that throws keeps its text and rejects the call. The [output reference](docs/core/output.md#a-streamed-message) states the contract.
- Add the `MessageArguments` type to `@loomcli/core`, the two argument lists a semantic method takes.
- Change `@loomcli/testing`'s builders so an unstated semantic lane reads a streamed message to its end before it resolves.
