- Fix the operator sentences of `@loomcli/plugins` that repeated a value without escaping it, so a control character, a line separator, or a bidirectional control in one prints as its `\uXXXX` escape instead of reaching the terminal or an MCP client. Only a value that holds such a character prints differently. Each changed sentence:
  - The MCP server's `Unknown tool "<name>". Call tools/list for the tool names.` escapes the tool name the client sent, and `Tool "<tool>" takes no argument "<key>". Use a property its input schema lists.` escapes the key, so a call naming `ec<U+202E>ho` is answered with `Unknown tool "ec\u202eho".` where the control itself came back. `Tool "<tool>" arguments must be an object. Supply a JSON object of named inputs.` escapes the tool name too.
  - The MCP server's `The request id <id> is in use by a request still in flight. Send each request with an id no request in flight holds.` no longer repeats the id, which the error response already carries as its `id`, so it reads `The request id is in use by a request still in flight. Send each request with an id no request in flight holds.` for every id. Before, an id that held a bidirectional control or a line separator reached the client's message raw.
  - The configuration plugin's `-v` line `Ignored option "<spelling>" from <label>: <issue>` and its strict line `Option "<spelling>" (from <label>): <issue>` escape the option's spelling, so an option declared as `fla<U+202E>g` prints `Ignored option "--fla\u202eg" from flag in .app.json: Use true or false.` The notice `Found no configuration file. Create <file> to configure <app>.` escapes the application's name.
  - The dotenv plugin's warnings `Skipped <file>: the file could not be read. Make it readable, or remove it.` and `Skipped <name> on line <line> of <file>: the line is not a valid assignment. Correct the line, or remove it.` escape the file's name, which repeats the mode `NODE_ENV` names.
  - The format plugin's issue `Supply one of <views>.` escapes each view name, and the help plugin's hint `Run "<command> --help" to see the usage.` escapes the application's name and each Command name.
  - Every sentence of the self-update and service plugins that names the application escapes its name, such as `<name> was not built as a release binary, so it cannot update itself.` and `<name> cannot run a service on <platform>.` A name core's portable rule accepts prints as before.
