- Name each unknown key in a configuration file at `-v`, as a dropped value is named, so an operator who misspells a setting such as `state_dir` for `stateDir` learns that the application did not read it: `Ignored state_dir in .collector.toml: Unknown key. Check its spelling, or remove it.` The configuration plugin judges the file against the JSON Schema the configuration schema publishes, by the rule its link check already uses, so a record, a loose object, and a `z.unknown()` section name nothing, and a schema with no JSON Schema, such as valibot's, prints no line. The lines follow the dropped-value lines, a key at or below a dropped value prints none, and the default verbosity is unchanged. The [configuration plugin](docs/plugins/config.md#naming-unknown-keys) reference states the rule.
