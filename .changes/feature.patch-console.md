- Add `patchConsole()` at `@loomcli/plugins/patch-console`, an opt-in plugin that keeps a dependency's `console` writes from tearing a live region. While a frame is on the stack, `console.log`, `info`, and `debug` write to the run's stdout and `console.warn` and `error` to its stderr through `out`, above the regions and under the run's rendering policy, and on Node a process warning follows `console.error`. The console comes back when the last frame leaves the stack and before the run ends, a failure included, and outside a region nothing is patched. The [patch-console plugin](docs/plugins/patch-console.md) page states the rules.
- Add the `onLiveRegions` lifecycle hook, with the `LiveRegionsHook` and `LiveRegionsHookContext` types. Core calls it with `'drawn'` when the run's first live region draws a frame and with `'closed'` when the last frame leaves the stack, in stderr's write order, for every region of the run, and hands it the run's `out`. [Observing live regions](docs/core/lifecycle-hooks.md#observing-live-regions) states the rules.
