- Add `mockProcess(fields)` to `@loomcli/testing`, with the types `MockFields`, `MockTerminal`, `MockProcess`, and `RecordingStream`. It builds a [process handle](docs/core/host.md#the-process-handle) that reads nothing from the process the test runs in: every fact has a sealed default, `stdout` and `stderr` record what a run writes, `exitCode` records what `run()` writes, and its signal source is its own. A test runs an Application with `app.run({ process: mockProcess(...) })` and reads the mock. See the [testing reference](docs/libs/testing.md#mockprocess).
