- Fix the time `loom` takes to start. The `loom` bin of `@loomcli/loom` is now one bundle, and each command loads its code only when it runs, so `loom --help` and `loom changelog check` no longer load the code of every command. Installing `@loomcli/loom` now installs no runtime dependency, and its optional peers, pnpm and TypeScript, are unchanged.
- Change how a defect inside `loom` itself reports: the bin is a distributed build, so it shows the generic defect message a distributed application shows in place of the Developer Diagnostic. See [development builds](docs/core/release-facts.md#development-builds).
- Fix a distributed `loom build` of a `node` or `bun` bundle shipping development code: it now runs Bun with `NODE_ENV` set to `production`, so the bundle resolves each dependency's production export and bundled code reads `production` from `process.env.NODE_ENV`, whatever the shell holds. A development build and `--watch` keep resolving development exports. See the [build reference](docs/toolchain/build.md#loom-build).
