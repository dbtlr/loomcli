- Mark every export of `@loomcli/prompts` and `@loomcli/prompts/views` with the TSDoc tag `@public`, as the [public exports](docs/core/public-exports.md) page describes, so its exports now carry tags and `check:api` covers the package. `@loomcli/prompts` now exports `PromptContext`, the slice of the action context a question takes, so a helper that asks several questions can name the context it passes on. `Answer`, `ChoiceAnswer`, `ChoiceValue`, and `Progress` are output types and carry `@sealed`, and so do `InteractionUnavailableError` and `EditorError`, which you catch and must not subclass. The settings, choice, and context types are input types, and so are the view data types under `@loomcli/prompts/views`, which an application may build by hand for `out.draw`, so none of them carries it.
