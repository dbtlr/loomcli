- Add `exclude` to `invoke`'s options, a list of declared option names the call leaves out of its run. No tier supplies an excluded option, so a variable or a configuration key bound to it is never read, it takes its declared default, a key of `options` that names it is an unknown option, and a name the routed Command's table does not hold is an unknown option too. The exclusion lasts for the one call.
- Add `mcpInput({ exclude: true })`, which keeps one option off an application's MCP tools while help, the manifest, and completion still show it. The server passes every excluded option under `exclude` on each tool call, so the action reads the declared default. A required local option that is excluded is the `@loomcli/plugins/mcp/required-input-excluded` build fault.
- Fix an option that carries only an `mcpInput({ description })` value in a `oneRequired` option group: its tool schema keeps the group's constraints.
