- Add Nushell completion. `jsonkit completion nu` prints a script that declares one extern for the application's name and asks the application at every Tab, and `jsonkit completion install nu` writes it into Nushell's vendor autoload folder, `$XDG_DATA_HOME/nushell/vendor/autoload`, by default `~/.local/share/nushell/vendor/autoload` on Linux and `~/Library/Application Support/nushell/vendor/autoload` on macOS, with no edit to `config.nu`; `update`, `uninstall`, and the self-update refresh act on it as on the other shells. Nushell 0.117 is the floor. Under a value hint for file names, Nushell lists every file name by its own rule, and completes none after an `=` or a short option's attached value, as [Completion](docs/plugins/completion.md#nushell) states.
