- Fix progress lines and other live regions redrawing in place on a terminal that cannot move its cursor. When stderr is a terminal and `TERM` is `dumb`, as in Emacs `M-x shell`, or `CI` is set and nonempty, a region opened without `input: true` reads `live` as `false`, so a progress line writes its plain start and end lines, `out.draw` keeps the Application's `terminalControls` setting, and a signal that ends the run writes no show-cursor sequence unless the Application preserves controls.
