- Add `format({ short })` to `@loomcli/plugins/format`, so an application can give `--format` a short spelling such as `-f`. Core judges it as it judges every option's short spelling, a spelling another option already holds is the hook-collision build error naming both, and `format()` with no settings still declares `--format` with no short spelling. See the [core reference](docs/core.md#formatter).
