- Add the `@loomcli/host-bypass` rule to `@loomcli/eslint-plugin`, on at `error` in `configs.recommended` and `configs.oxlint`, under [ADR-0107](docs/decisions/0107-a-run-reads-the-process-through-one-process-handle.md). It reports the global `process`, `globalThis.process`, and `global.process`, an import of `process` or `node:process`, `homedir`, `tmpdir`, and `userInfo` from `os` or `node:os`, and an import of `child_process` or `node:child_process` in an application's source, and each message names the host member to use instead, such as `host.env`, `host.home`, `host.tmpdir`, or `host.spawn`. A file whose name holds `.test.` or `.spec.` is not linted by it. `loom init` writes the rule into a new scaffold's lint file. See the [plugin reference](docs/libs/eslint-plugin.md#host-bypass).
