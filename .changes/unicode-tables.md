- Change `@loomcli/core` to carry its Unicode width tables as a JavaScript module, so it reads no file at run time and any bundler, such as `Bun.build` or Rolldown, bundles a Loom application that starts under Node and Bun. Core no longer depends on `@rockorager/uucode`, and text measures and pads to the same columns as before. Core's license field reads `MIT AND Unicode-3.0`, because the tables derive from Unicode data, and the package ships the license texts in `licenses/` with a `NOTICE`.
- Change `packet()` from `@loomcli/loom/build` to answer the packet alone. It no longer carries data files into the bundle, and an application bundled without it starts and reads its source packet, `development`. See [Development builds](docs/core.md#development-builds).
