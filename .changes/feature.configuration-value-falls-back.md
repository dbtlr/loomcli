- Change a value the configuration source filled and the option's validator rejects to fall back instead of failing the run. The option reads as unfilled: its default applies, a `required` option reports its missing-value error, and `validateOmitted` receives `undefined`. A dropped fill activates no middleware, and one rejected item drops a multiple option's whole list. Core writes one `out.debug` line for each, `Ignored option "--limit" from limits.bytes in fixture.json: Supply a whole number.`, which shows at `-v`. A value from argv or the environment that its validator rejects still fails with code 2.
- Add an optional `directory` to `SourceAnswer`, the absolute path of the directory of the file a value came from. The option's validator receives a context whose `host.cwd` is that directory, so `path()` resolves a relative value against the file. A `directory` that is not an absolute path is a defect of the source.
