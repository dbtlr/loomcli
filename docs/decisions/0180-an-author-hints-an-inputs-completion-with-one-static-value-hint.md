# ADR-0180 - An author hints an input's completion with one static value hint

## Context

An option or an argument that names no closed set completes file names, because the answer ends with directive `0`. An author whose `--config` reads only `.json` files, or whose `--into` names a folder, or whose argument names no file at all, has no way to say so. clap's `ValueHint` and Cobra's `MarkFlagFilename` and `MarkFlagDirname` give an author that vocabulary.

[ADR-0043](0043-shell-completion-follows-cobras-protocol-and-never-evaluates-typed-text.md)'s **What is offered** clause names canonical Command names, option spellings, and the values of a closed set, and its consequences leave the shell to complete paths itself under directive `0`. Today the answer writes only `0`, `1`, and `4`, as the [completion reference](../plugins/completion.md) states, and the scripts, ported from Cobra, already carry Cobra's handling of directives `8` and `16`, except that Cobra's Fish script completes every file name under both, as the package NOTICE states. [ADR-0043](0043-shell-completion-follows-cobras-protocol-and-never-evaluates-typed-text.md)'s no-evaluation rule is absolute, so a hint can name no function a shell runs. The help Command's `command` argument takes a Command path, and completion offers it nothing today, which [ADR-0140](0140-the-help-plugin-attaches-a-help-command-on-opt-in.md) deferred to later completion work.

## Decision

- **Two plain-data extensions, one hint each.** `@loomcli/plugins/completion/extension` exports `completionInput`, on options, and `completionArgument`, on arguments, with identities `@loomcli/plugins/completion/input` and `@loomcli/plugins/completion/argument`. An argument's facts type is `CompletionValueFacts`, and an option's is `CompletionInputFacts`, the same union without the `commands` member, because only an argument's earlier words name a path of Commands. The module holds declarations alone, as the MCP and help extension modules do under [ADR-0020](0020-first-party-plugins-ship-in-one-package-as-subpaths.md), and the plugin registers both descriptors. The value is exactly one of `{ files: true }`, `{ extensions: [...] }`, `{ directories: true }`, `{ none: true }`, and, on an argument, `{ commands: true }`, each key beside the other four held absent, so a later task adds a named-completer member, such as `{ values: '<name>' }`, as a new union member without changing one that exists. The types reject a value with two hints or none, and `commands` on an option. A value that bypasses them, or holds an empty or malformed `extensions` list, which only the schema rejects, is core's invalid-extension-value fault, with no new rule, under [ADR-0093](0093-a-value-that-bypasses-the-types-gets-no-rule.md). An extension is a name without its dot that starts with an ASCII letter or digit and holds letters, digits, `.`, `_`, `+`, and `-`, so a script compares it as text and no shell reads a glob in it.
- **The answer.** `files` offers nothing with directive `0`. `extensions` offers the extensions as the words, with no prefix filter, with directive `8`, as Cobra does. `directories` offers nothing with directive `16`. A value in its own word carries no lead under either; a value attached to its option leads the answer with its lead, as the attached-value rule below states. `none` offers nothing with directive `4`. The plugin now writes `0`, `1`, `4`, `8`, and `16`.
- **A closed set wins.** An input whose schema names a closed set offers the set with directive `4` and its hint is not read. A hint beside a set could only offer an operator a word the validator rejects or hide one it accepts, so the set is the one source and no fault is added.
- **Commands.** `commands` offers the listed children of the Command reached from the root through the words the argument holds so far, the words `locate` reports in `typed` for that argument. Each word routes by canonical name or any alias, hidden and deprecated Commands included, as the help Command routes, and an unknown word reaches nothing. The offered children follow the existing command-position rules, with directive `4`. The help Command declares the hint on its `command` argument by importing the extension module; help imports no other completion module. [ADR-0031](0031-a-plugin-supplies-facts-to-another-plugins-projection-through-a-collecting-extension.md) scoped a plugin's import of a sibling's declarations to supplying a collecting extension, and this hint is not a collecting extension, so this record widens that grant: a plugin may import a sibling's declarations module to set a value on its own Command or input, as help does, or to read a descriptor's identity, as the MCP plugin does to count the completion hints among the extensions that bind nothing. Every `help()` application then bundles the completion declarations module, which holds declarations and its schemas alone.
- **A Command position with children.** Where an argument with a filtering hint, `extensions` or `directories`, shares a position with a Command's children, a child whose name starts with the prefix is offered with directive `4`, and the file filter applies only where none does, because a script that filters file names lists no offered word. This narrows [ADR-0160](0160-a-command-with-an-action-may-declare-arguments-and-hold-children-and-an-exact-child-name-routes-first.md)'s rule that such a position offers the children with directive `0` when its argument has no closed set: a hinted argument's directive applies instead.
- **A value attached to its option.** Under `8` and `16`, a value typed in its option's word, as in `--config=a`, `-ca`, or a short group `-vca`, has the answer write the lead `locate` reports, `--config=`, `-c`, or `-vc`, as its first word. No extension starts with `-`, so a script reads such a first word as the lead, lists the file names for the rest of the word, and inserts each behind the lead. Only the answer knows where a short group's value starts, so no script guesses it from the word. The first word under `16` is never a folder to list in, as Cobra's scripts read it, because the answer never names one.
- **Every script honors `8` and `16` with no other name, Fish included.** Each script lists the directories and, under `8`, the names that end in an offered extension, compared as strings, and never falls back to every file name. The Bash script lists them by its own pathname expansion, with or without the bash-completion package, rather than through `_filedir`, whose extension match ignores case, and turns default file completion off where `compopt` exists. The Zsh script lists them itself, as it does under directive `0`, by a glob of the quoted folder part of the typed word with only a trailing `*` live, and offers them with `compadd -f`, rather than through `_files`, which falls back to every file, or `_path_files`, which, like `_files`, expands a command substitution in the folder part of the typed word, such as `$(…)/`. The Fish script replaces Cobra's fall back to every file name with a listing built from Fish's own expansion of a variable followed by `*`, which expands no wildcard, command, or tilde the typed word holds, so nothing typed is evaluated, and a `~` in the typed word is matched as a literal character.
- **Core does not change.** `inspect()` reports a hint as an ordinary extension value, and the manifest leaves it out as it leaves out every extension value, under [ADR-0019](0019-plugin-facts-are-descriptor-keyed-extension-values-and-core-owns-the-universal-facts.md), and a hint is inert where the completion plugin is not installed.

## Considered options

- **A single key with a tag, such as `{ hint: 'files', extensions: [...] }`.** Rejected: it lets a value carry an `extensions` list beside a hint that reads none, which the types must then forbid by a second rule. One key per hint makes the exclusion the shape.
- **One descriptor for options and arguments.** Not possible: a descriptor has one target, so the plugin ships two, whose facts differ only in the argument's `commands` member.
- **A fault when a hint sits beside a closed set.** Rejected: it needs a new rule and its generated documentation to catch a case in which the closed set already gives the operator only valid words.
- **Keeping Cobra's Fish behavior for `8` and `16`.** Rejected: with a hint, Fish would list every file for an input an author marked JSON only, while the other three shells filter, and nothing in Fish needs an evaluation to filter.
- **A hint that names a function the shell runs.** Rejected by [ADR-0043](0043-shell-completion-follows-cobras-protocol-and-never-evaluates-typed-text.md): nothing typed or declared is evaluated by a script. A named completer that the application computes is a separate decision.

## Consequences

This narrows [ADR-0043](0043-shell-completion-follows-cobras-protocol-and-never-evaluates-typed-text.md)'s **What is offered** clause, so the answer also offers a hint's extensions, a lead, and the Commands an argument has reached, and its consequence that the shell completes paths itself under directive `0`, because a hinted input has the script list paths under `8` or `16`, or none under `4`. It narrows [ADR-0160](0160-a-command-with-an-action-may-declare-arguments-and-hold-children-and-an-exact-child-name-routes-first.md)'s directive `0` at a `command` position whose argument has a hint, ends [ADR-0140](0140-the-help-plugin-attaches-a-help-command-on-opt-in.md)'s deferral of completing Command names for the help Command's `command` argument, and widens [ADR-0020](0020-first-party-plugins-ship-in-one-package-as-subpaths.md)'s grant, as [ADR-0031](0031-a-plugin-supplies-facts-to-another-plugins-projection-through-a-collecting-extension.md) scoped it, to import a sibling's declarations module. Each of ADR-0020, ADR-0043, ADR-0140, and ADR-0160 carries a dated entry. The [completion reference](../plugins/completion.md) states the extensions, each hint's offered words and directive, the lead, and each script's listing, the package NOTICE states the script changes, and the [help reference](../plugins/help.md#the-help-command) states the `command` argument's hint. An application that hints an input with an extension and a validator that names a set gets the set.

## Status

Proposed. It moves to accepted in the release PR of the release that ships it.
