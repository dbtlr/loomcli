- Fix TypeScript 7.1 accepting a Command that cannot attach where it is attached, and an Application where a type annotation names globals, arguments, or options it does not declare. Under TypeScript 7.1, an Application's `command()` and a plugin's `commands` list accepted a Command that reads a global option the receiver does not declare, such as one a provider in its `uses` reads or one the registered Application declares, and `command()` accepted a union of Commands in which one branch declares a local option that repeats a global option's key. Under TypeScript 7.1, a value annotated as `Application<Args, Options, Globals>` accepted an Application whose declarations differ. TypeScript 7.1 now reports the same compile error for each as TypeScript 7.0. Code that compiles under TypeScript 7.0 is unchanged.
