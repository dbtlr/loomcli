- Fix `install.sh --unmanaged --dir <directory>` replacing the binary that `install.json` records. When `<directory>/<name>` is the recorded binary, the script now fails before it downloads anything, exits 2, and leaves the binary and the record as they were: `<name>: --unmanaged cannot install into <directory>, which holds the installation that install.json records. Choose another directory for the side copy with --dir.` It used to install over the binary and leave the record naming the old digest, so the next self-update or digest check met a record that no longer matched. A directory the record does not name installs as before. Run `loom init --only install` to render the new script.
